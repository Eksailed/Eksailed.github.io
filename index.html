Флагманский проект

AstroBot — Персональный AI-астролог + Mini App

Полноценная экосистема персонализированного астрологического сервиса: высокоточные астрономические расчеты швейцарских эфемерид (Swiss Ephemeris), контекстный чат с ИИ на базе Qwen 2.5 72B, Telegram Stars монетизация и встроенный интерактивный Mini App на React 18.

  • Модульная архитектура: жесткое разделение слоев (bot, api, services, db, webapp)
  • FastAPI REST API с криптографической валидацией HMAC-SHA256 (Telegram initData)
  • PostgreSQL + SQLAlchemy 2.0 Async + asyncpg + миграции Alembic
  • Redis для суточных лимитов запросов (Rate Limiting) и сессий
  • Монетизация через Telegram Stars (XTR) и подписку PRO
  • Полная контейнеризация всей связки сервисов в Docker Compose

Нейросети с контекстной инъекцией

Вместо стандартных шаблонных ответов — динамическая подмешивание актуальных данных в системный промпт модели Qwen 2.5 72B через OpenRouter API.

  • Точная инъекция натального паспорта и транзитов планет в контекстное окно модели.
  • Обработка суточных квот и лимитов токенов с мягким объяснением пользователю.
  • Строгая валидация входящих и выходящих данных через Pydantic v2.
  • Защита персональных данных: команда полного удаления истории (/delete, GDPR compliance).

Реализовано в проекте AstroBot.

Асинхронный бэкенд без узких мест

Использую современный стек Python 3.11+: FastAPI, асинхронный SQLAlchemy 2.0 с драйвером asyncpg и Redis для мгновенного кэширования.

  • Паттерн Repository для изоляции бизнес-логики от базы данных.
  • Автоматические миграции схемы БД через Alembic.
  • Контроль частоты запросов (Rate Limiting) через Redis.
  • Валидация Telegram WebApp initData по алгоритму HMAC-SHA256.

Отработано в бэкенд-сервисе AstroBot API.

# Async DB Session Middleware class DbSessionMiddleware(BaseMiddleware): async def __call__(self, handler, event, data): async with self.session_pool() as session: data["session"] = session return await handler(event, data)

Предсказуемый деплой в Docker

Любой проект упаковывается в docker-compose.yml и разворачивается одной командой на любом Linux VPS без проблем с зависимостями.

  • Мультиконтейнерная сборка: PostgreSQL 15 + Redis 7 + FastAPI Backend + Telegram Bot.
  • Изоляция сетевого окружения (bridge networks) и персистентные тома для данных (volumes).
  • Healthcheck-проверки и автоматический перезапуск упавших контейнеров.
  • Фоновые периодические задачи через APScheduler.

Готовая конфигурация в репозиториях astrobot и football_bot.

# docker-compose.yml services: db: image: postgres:15-alpine volumes: [postgres_data:/var/lib/postgresql/data] redis: image: redis:7-alpine bot: build: . depends_on: [db, redis] restart: unless-stopped
